# Privacy Policy for Revit Drive Connector

**Last updated:** November 15, 2026

## 1. Overview
Revit Drive Connector ("the Software") is a multi-user BIM worksharing add-in for Autodesk Revit designed to facilitate secure cloud collaboration using Google Drive.

## 2. Information We Collect and Access
The Software accesses only the data strictly necessary to provide its core synchronization and collaboration features:
* **Google Account Information:** When you sign in via Google OAuth 2.0, the Software retrieves basic profile details (email address and display name) solely to identify you as an active collaborator within project sessions.
* **Google Drive Access:** The Software uses Google Drive API v3 to read and write BIM project folders, Revit models, external links (CAD/IFC), and project manifests located in folders created or shared by you and your authorized team members.

## 3. Data Storage and Third Parties
* **Zero External Telemetry:** All authentication tokens, project cache files, and settings are stored strictly on your local machine (%APPDATA%\RevitDriveConnector and local cache) and within your Google Drive account.
* **No Third-Party Sharing:** We do not collect, transmit, sell, or share any personal information, project files, or telemetry to external servers, advertising networks, or third parties.

## 4. Security and Tokens
OAuth 2.0 access and refresh tokens are stored securely in your local user profile. You can revoke access at any time directly through the "Account Google" menu in the Revit add-in or via your Google Account Security dashboard (https://myaccount.google.com/permissions).
